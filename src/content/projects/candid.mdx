## À propos du projet

Candid est un assistant de candidature Android **entièrement autonome** : pas de serveur, pas d'hébergement, tout tourne sur le téléphone. On partage une offre depuis LinkedIn, France Travail ou Welcome to the Jungle ; l'app normalise, déduplique, score localement, puis un agent LLM produit un CV ciblé et une lettre en PDF. La relecture et l'envoi restent **humains**. C'est le compagnon mobile du projet Docker [job_hunter](https://github.com/benjsant/job_hunter), pensé pour la cible de partage Android que la version serveur ne peut pas avoir.

## Choix d'archi notables

- **Trois règles non négociables, inscrites dans le code.** L'app ne doit jamais inventer une compétence ou une expérience, jamais envoyer automatiquement, jamais modifier des données perso sans validation. Ces garde-fous vivent dans `lib/agent/guards.dart` et `lib/domain/dedup.dart`.
- **Agent LLM ancré.** Analyse de l'offre, ancrage sur des faits vérifiables, génération d'accroche, passage par un juge, puis validation. Pas de broderie.
- **100% on-device.** Aucun backend à héberger ; les seuls appels sortants vont vers des API publiques. Génération PDF sur l'appareil.
- **Human-in-the-loop strict.** L'app produit des PDF et s'arrête là : c'est l'utilisateur qui relit et envoie.
- **Documentation technique complète** publiée sur GitHub Pages (architecture, modèle de données, agent, sources, audit de sécurité, journal des décisions).

## Stack technique

| Couche | Stack |
| ------ | ----- |
| App | Flutter 3.44 + Dart, min SDK Android 7.0 |
| IA | Agent LLM (Gemini), ancrage sur des faits vérifiables, juge |
| Partage | `receive_sharing_intent` (Android share target) |
| Sortie | Génération de CV et lettre en PDF sur l'appareil |
| Documentation | Doc technique sur GitHub Pages |
