## À propos du projet

Veille technique automatisée sur l'écosystème Data Engineering, MLOps et IA. Le système agrège des sources RSS, élimine les doublons et génère un digest intelligent chaque jour.

## Workflows n8n

**Workflow 1, Agrégation RSS**
Lit 4 flux RSS toutes les 24h (Medium, Dev.to, Towards Data Science, The Batch), filtre les articles récents, déduplique les entrées et envoie un digest structuré sur Discord. Limite à 3 articles Medium pour éviter le spam.

**Workflow 2, Rapport IA DeepSeek**
Appelle l'API DeepSeek pour générer un rapport de veille structuré sur les thèmes IA, Data Engineering, MLOps et Cloud. Formate la réponse en embeds Discord avec scores de pertinence et recommandations de lecture.

## Ce que ça démontre

- Intégration d'APIs LLM en production (DeepSeek)
- Orchestration de workflows sans code avec n8n
- Automatisation de processus métier répétitifs
- Notification et reporting automatiques

## Stack technique

- **Orchestration** : n8n (self-hosted)
- **IA** : DeepSeek API
- **Sources** : RSS (Medium, Dev.to, Towards Data Science)
- **Output** : Discord Webhooks avec embeds formatés
