Pokédex complet pour Pokémon Let's Go Pikachu/Évoli — 188 Pokémon, 226 capacités, 18 types — avec deux fonctionnalités IA : synthèse vocale des descriptions (Coqui TTS) et assistant conversationnel RAG (DeepSeek + pgvector).

## Ce que j'ai construit

- Pipeline ETL en 8 phases : CSV → PokéAPI → scraping Pokepédia (Scrapy) → pgvector embeddings
- Recherche vectorielle avec `sentence-transformers` (all-MiniLM-L6-v2, 384 dimensions) et index ivfflat
- Agent DeepSeek avec 3 outils : `sql_search`, `vector_search`, `web_search` (SearXNG)
- Synthèse vocale TTS des fiches Pokédex via Coqui
- Calcul bi-type (faiblesses ×2/×4, résistances, immunités)
- Monitoring Prometheus + Grafana
