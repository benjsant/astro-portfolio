## À propos du projet

InfiniDex MCP est un serveur [Model Context Protocol](https://modelcontextprotocol.io) qui expose les données structurées d'[InfiniDex](https://github.com/benjsant/InfiniDex) (Pokémon Infinite Fusion) à n'importe quel client MCP : Claude Desktop, Claude Code, Cursor, Windsurf. Là où InfiniDex expose déjà un agent LLM via HTTP pour son frontend, ce serveur permet à un assistant de coder ou un IDE d'**interroger directement** les données, sans toucher au site.

## Choix d'archi notables

- **Un pont, pas un couplage.** Le serveur fait le lien entre un client MCP et l'API REST d'InfiniDex. Il n'a **aucune dépendance** sur le runtime InfiniDex : seulement son URL. On peut le faire évoluer sans toucher au backend.
- **Deux transports.** stdio (intégration locale directe dans un client) ou HTTP.
- **100% local.** Tout tourne sur la machine, en Docker. Aucune publication, aucun service externe.
- **Interface CLI** pour tester les tools hors d'un client.

## Stack technique

| Couche | Stack |
